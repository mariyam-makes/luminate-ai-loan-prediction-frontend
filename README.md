# 🌟 Luminate – Loan Prediction Dashboard

Welcome to the frontend application for **Luminate**, a modern loan eligibility prediction platform. This dashboard provides an intuitive user experience for submitting applicant information, viewing prediction results, and monitoring model insights.

---

## 🚀 Key Features

### Interactive Loan Predictor
A user-friendly prediction form that allows users to enter applicant details such as income, credit history, loan amount, and other financial attributes to receive instant loan eligibility predictions.

### Modern UI/UX
Built with **Next.js** and **Tailwind CSS**, featuring a responsive black-and-purple themed interface optimized for desktop and mobile devices.

### Live API Integration
Seamlessly connected to a FastAPI-powered machine learning backend for real-time prediction requests and results.

### Analytics Dashboard
Visualize model performance, prediction statistics, approval trends, and other key metrics through interactive charts and data cards.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **Charts & Visualization:** Recharts
- **API Communication:** Fetch / Axios
- **Backend Integration:** FastAPI + Scikit-learn KNN Model
